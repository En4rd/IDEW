# IDEW

**IDEW** (Imágenes de Excel a Word) es un pequeño programa con varias herramientas diseñadas para facilitar tareas comunes de oficina. Está enfocado especialmente en la manipulación de documentos de Excel y Word.

## Características Principales

- Copiar grandes cantidades de rangos desde Excel a Word.
- Pegar imágenes secuenciales en celdas de Excel.
- Colocar puntos enumerados en layouts automáticamente.
